## J e v eration: System One Models Now Generate

System One models such as Jev return decisions through fast, parallel prediction. In this paper, we introduce Jeveration, showing that the same decision paradigm can also generate high-quality images in a single forward pass. Jeveration builds on a frozen vision-language model, repurposing its visual-semantic knowledge for holistic image generation. The key challenge is to maintain global consistency. A single prompt admits many valid images, yet parallel predictions must converge on a coherent whole. We therefore condition all positions on a shared random state to coordinate parallel predictions, so that each draw yields a different but coherent image. Since the model tends to ignore this state under direct image supervision, we first learn a distribution over discrete image codes to guide single-pass generation. Beyond text-to-image generation, we further unify image-to-image generation and dense prediction within the same architecture, so that one checkpoint supports all three tasks, each in one forward pass. Experiments show that Jeveration generates a $512{\times}512$ image in 78 ms, up to 122 $\times$ faster than existing unified models, while maintaining competitive image quality and dense prediction performance.

### 1 Introduction

Image generation today is dominated by two paradigms. Autoregressive models [ 40 , 44 , 11 ] generate an image token by token, while diffusion models [ 8 , 48 , 25 ] generate it by iterative denoising. Both generally require many sequential model evaluations for a single image, which increases inference latency. We introduce a third paradigm for image generation that removes sequential sampling, built on System One models. Our model, Jeveration, returns a complete image as one joint decision in a single forward pass, given a text prompt or a source image ( Fig. 1 ).

System One models such as Jev [ 1 ] return typed decisions, such as Choices or Scores, in a single parallel query without extended reasoning [ 1 ] . They have been applied to option selection, object localization, robot action scoring, and image evaluation [ 12 , 42 , 43 , 26 , 27 ] . Their effectiveness in these decision-making and understanding tasks draws in part on the visual and semantic knowledge acquired through large-scale pretraining. This knowledge also offers a foundation for image synthesis, suggesting that System One models have generative potential beyond their current uses. Motivated by this potential, we first explore a direct approach: using a System One model to select an entry from an existing codebook for every code position in a single forward pass. Our initial attempts, however, reveal two key challenges. First, direct parallel selection does not ensure global coherence. A single prompt admits many valid images, thus parallel decisions at different positions may correspond to incompatible realizations, producing image regions that fail to fit together, as illustrated in Fig. 2 . Second, extending this approach to diverse image generation tasks requires a unified architecture that accommodates different inputs and conditioning requirements.

To keep the image globally consistent, we condition all positions on a shared random state that coordinates the parallel predictions, so that each draw yields a different but coherent image. Furthermore, since a model trained on target images alone tends to ignore this state, we first train a model that learns the distribution of images as discrete codes, and then use it to judge the single-pass decisions and guide their training. The same paradigm extends to further tasks whose output is an image. Image-to-image generation uses a source image or visual conditions, such as edges, depth or grayscale, to guide the content and appearance of the generated image. Dense prediction can be regarded as image-to-image generation in a broad sense, where the model generates a map aligned with the input image that specifies a class, depth or surface normal at each pixel. One model can thus cover generation as well as perception.

Putting these together, Jeveration starts from a vision-language model (VLM), Qwen3.5-4B [ 41 ] , and lets it answer visual tasks with Jev-style decisions. The VLM stays frozen, and Jeveration adds only LoRA adapters [ 21 ] and output heads. Each answer, whether an image or a dense map, is one typed decision made in a single forward pass, and one checkpoint covers text-to-image generation, image-to-image generation and dense prediction tasks. It reaches 0.74 GenEval at 512 px in 78 ms per image on one H200, 122 $\times$ faster than Janus-Pro-7B [ 11 ] , closely follows the input structure in image-to-image generation, and achieves competitive results on dense prediction. These results show that a decision model itself can generate images and predict dense maps in a single forward pass. Our contributions are:

- • Image generation through typed decisions. To our knowledge, this is the first work to show that Jev-style system one models can themselves generate images in one forward pass, for both text-to-image and image-to-image generation.

- • Learning coherent image decisions. We let parallel decisions form one coherent image by conditioning them on one shared random state, and train the model to use this state by first learning the image distribution and then using it to judge and guide the decisions.

- • One checkpoint across visual outputs. One checkpoint with shared adapters performs text-to-image generation, image-to-image generation and dense prediction. Extensive experiments and ablation studies on these tasks demonstrate its effectiveness and efficiency.


### 2 Related work


##### Unified multimodal understanding and generation.

Unified multimodal models combine image understanding and synthesis. Chameleon [ 40 ] , Emu3 [ 44 ] , Janus/Janus-Pro [ 45 , 11 ] and Unified-IO 2 [ 33 ] generate image tokens autoregressively. Show-o [ 49 ] uses masked prediction, while Transfusion [ 56 ] and BAGEL [ 14 ] model continuous image latents. MetaQueries [ 36 ] and BLIP3-o [ 9 ] instead connect understanding representations to separate diffusion generators. All of these models generate an image over many sequential steps, token by token or by iterative denoising. Dense prediction is another route to visual outputs. For instance, LENS [ 32 ] adds segmentation to a frozen multimodal model, while DenseMLLM [ 29 ] supervises visual tokens for dense prediction. In contrast, Jeveration unifies image synthesis and dense prediction by formulating both as parallel typed decisions, using a single frozen VLM with shared adapters and task-specific output heads.


##### One-step image generation.

Single-pass generators learn to turn a random input into an image without iterative sampling. Consistency models [ 39 ] and MeanFlow [ 18 ] learn direct generation in continuous spaces. DMD/DMD2 [ 53 , 52 ] , SANA-Sprint [ 10 ] and TwinFlow [ 13 ] provide further approaches to one-step or few-step synthesis. Acceleration also applies to unified models. For example, Show-o Turbo [ 50 ] uses consistency distillation, and Omni-Diffusion-Distill [ 23 ] compresses multimodal decoding trajectories. For discrete images, MaskGIT [ 5 ] , Muse [ 6 ] and Meissonic [ 3 ] learn masked-code conditionals and sample over multiple rounds. Di[M]O [ 57 ] distills such a model into a one-step generator by matching its token-level conditionals with the help of an auxiliary model. Soft-Di[M]O [ 58 ] further uses soft embeddings to enable differentiable refinement. Building on this line of work, Jeveration adapts token-level conditional matching to learn coherent image synthesis through the parallel typed decisions of a frozen VLM. Its target conditionals are provided by a masked model first trained on the same frozen backbone, while a confidence-guided correction target further guides parallel code selection.


##### Typed decision models.

Jev [ 1 ] returns typed outputs such as Choices, Scores, and probabilities in parallel without generating lengthy text, while its Box interface predicts the four edges of an object’s bounding box [ 42 ] . Open decision models [ 12 , 19 , 2 ] and a clinical decision model [ 55 ] similarly provide structured decision outputs. Jeva [ 28 ] explicitly addresses candidate-set scalability, demonstrating full-set decision-making with up to 2,048 candidates in its evaluation. These decision interfaces also support specialized applications: Qwen-Audio-Jev [ 17 ] answers typed questions about audio, JevVLA [ 43 ] scores and corrects robot actions, and Visual Jev Rewards [ 26 ] evaluates generated images to reward a separate generator. Jeveration extends this paradigm to spatially coordinated image generation, predicting all image tokens in parallel within a single forward pass conditioned on a shared random state. The same model also predicts dense maps in one pass, using a class Choice at each position for segmentation and Scores for depth and surface normal estimation.


### 3 Method

Jeveration enables a VLM to generate images through parallel typed decisions in a single forward pass, while supporting dense prediction within the same framework. As shown in Fig. 3 , for image synthesis, these decisions select a codebook entry at each code position, while for dense prediction they produce task-specific classes or scores. A shared random state gives all code positions common stochastic conditioning, so that each draw yields a different but globally coherent image. We first formalize these visual decisions and the role of shared randomness ( Sec. 3.1 ). We then describe how a frozen VLM with shared adapters and task-specific output heads supports these tasks within one checkpoint ( Sec. 3.2 ). Finally, we present the training procedure that teaches the model to produce coherent images through parallel decisions ( Sec. 3.3 ).

Decision tokens start from a random state for image generation, while for dense prediction they act as spatial queries. Task-specific heads then map their final hidden states to image codes or dense predictions. One checkpoint serves all tasks.


#### 3.1 Images as Decisions

Given a condition $y$ , which holds a prompt or an input image, Jeveration answers with typed decisions [ 1 ] . An image is a joint Choice of discrete codes $c=(c_{1},\ldots,c_{N})$ of an image tokenizer, segmentation is a Choice over semantic classes at each spatial position, and depth and surface normals are real-valued Scores at every position. A dense map has one correct answer per input and is decided deterministically, whereas one prompt admits many valid images, so an image decision should be stochastic.


##### Why a joint decision is hard.

Given the conditioning input $y$ , such as a text prompt or a source image with instructions, a direct approach predicts a categorical distribution at each code position and samples the codes independently in parallel:

[Tableau] $$q_{\mathrm{ind}}(c\mid y)=\prod_{i=1}^{N}q_{i}(c_{i}\mid y).$$ (1)

This factorisation cannot capture dependencies between codes. For a fixed condition $y$ and target distribution $p(c\mid y)$ , its best forward-KL approximation satisfies

[Tableau] $$\min_{q_{\mathrm{ind}}}\mathrm{KL}(p\,\|\,q_{\mathrm{ind}})=\sum_{i=1}^{N}H(c_{i}\mid y)-H(c\mid y),$$ (2)

where $H$ denotes entropy under $p$ given $y$ . The gap is the target’s total correlation, which measures how strongly the codes of an image depend on each other. A coherent image needs this dependence, but an independent model matches only the marginals $p(c_{i}\mid y)$ , so its codes may follow different images and fail to fit together ( Fig. 2 ).


##### A shared random state.

Jeveration draws one random state sequence $\xi$ per image and conditions every code position on this shared state:

[Tableau] $$q_{\theta}(c\mid y)=\mathbb{E}_{\xi\sim p_{0}}\!\left[\prod_{i=1}^{N}q_{\theta,i}(c_{i}\mid y,\xi)\right].$$ (3)

The shared state $\xi$ provides a common source of randomness for all image positions. Although the codes are sampled independently given $(y,\xi)$ , their shared dependence on $\xi$ allows the resulting image distribution to capture dependencies between positions. The model can therefore coordinate its code choices while deciding all positions in a single forward pass. What remains is to learn how to use $\xi$ to produce coherent images ( Sec. 3.3 ).


#### 3.2 Architecture and Inference


##### Overall architecture.

We implement these visual decisions by appending decision tokens to the input of a VLM, as shown in Fig. 3 . Text tokens encode the prompt and task instruction, and a frozen vision tower encodes any input image into visual tokens. The decision tokens are initialised from a sampled random state for image generation and serve as spatial queries for dense prediction. A frozen Qwen3.5-4B [ 41 ] backbone with shared LoRA adapters [ 21 ] processes the input and decision tokens in a single forward pass. In its full-attention layers, decision tokens attend to each other bidirectionally while the input prefix remains causal. Finally, task-specific heads map the decision tokens’ final hidden states to image codes or dense predictions. The same checkpoint is used for every task.


##### Image generation.

The image tokenizer is a frozen TA-TiTok [ 54 , 24 ] with $N=128$ codes per image. For image generation, we append $N$ decision tokens, and the $i$ -th token decides the code $c_{i}$ . The initial embeddings of these tokens encode the random state $\xi\sim p_{0}$ , which masks each position with probability $\rho$ , fills the remaining positions with uniformly random codes and adds Gaussian noise of scale $\sigma$ to all embeddings. Following Di[M]O [ 57 ] , we set $\rho=0.6$ and $\sigma=0.1$ . A transformer head [ 37 ] reads the final hidden states of these tokens together with $\xi$ and outputs a feature $u_{i}$ for each position. We predict each code from $u_{i}$ with two branches. The codebook branch $f_{\mathrm{cb}}$ projects $u_{i}$ to the code space and applies a classifier initialised from the tokenizer’s codebook. The wide branch $f_{\mathrm{wide}}$ , initialised at zero, maps $u_{i}$ directly to the code logits, giving the head more freedom to learn. The code distribution sums the two:

[Tableau] $$q_{\theta,i}(\cdot\mid y,\xi)=\operatorname{softmax}\big(f_{\mathrm{cb}}(u_{i})+f_{\mathrm{wide}}(u_{i})\big).$$ (4)

Both branches are trained and we conduct ablations in Sec. 4.4 to show the benefit of combining them. At inference, all codes are sampled in parallel as one joint decision. Finally, they are rendered by the tokenizer’s decoder, which also reads the prompt and which we fine-tune for 512-px output. For image-to-image generation, a gated branch also feeds the source image to the decoder.


##### Dense prediction.

For dense prediction, the decision tokens are spatial queries aligned with the visual tokens of the input image. Each query starts from a learned vector plus a projection of its visual token. Task-specific heads decode each query’s final hidden state into the segmentation, depth or surface-normal predictions for its image region.

#### 3.3 Learning to Decide

We train the model to use $\xi$ to make coherent image decisions. Direct supervision on target codes does not encourage the model to use $\xi$ , since the random state is sampled independently of the target image. We therefore first learn a model of the image distribution through masked prediction, then use it to guide image decisions from random states.


##### Learning the image distribution.

In the first phase, we train the architecture as a masked model [ 5 , 6 ] , keeping the VLM frozen. For target codes $c$ , we mask a random set $M$ and predict the hidden codes from the visible codes $c_{\bar{M}}$ and condition $y$ :

[Tableau] $$\mathcal{L}_{\mathrm{mask}}(\phi)=\mathbb{E}\!\left[\frac{1}{|M|}\sum_{i\in M}-\log p_{\phi,i}(c_{i}\mid c_{\bar{M}},y)\right].$$ (5)

The visible codes supply image-specific context, enabling the model to learn dependencies between positions. The resulting model provides reference conditional predictions for the second phase.


##### Learning image decisions.

In the second phase, the decision model $\theta$ starts from the first-phase model and learns to turn random states into whole images. From $(y,\xi)$ , $\theta$ predicts logits $\ell_{\theta,i}$ and samples a code sequence $\hat{c}$ in a single pass. We re-mask a random subset $M$ of $\hat{c}$ , and two masked models predict the hidden codes from the same visible codes. The frozen first-phase model $\phi$ represents the image distribution and gives $p_{\phi,i}$ . An auxiliary model $\psi$ gives $p_{\psi,i}$ for the current distribution of $\theta$ . The auxiliary model begins as a copy of $\phi$ and keeps training on $\theta$ ’s samples with the masked loss of Eq. 5 , so it follows $\theta$ as $\theta$ changes. The two predictions agree when $\theta$ matches the image distribution. Following Di[M]O [ 57 ] , we use their difference to update $\theta$ by minimising

[Tableau] $$\mathcal{L}_{\mathrm{DM}}(\theta)=\mathbb{E}\!\left[\frac{1}{|M|}\sum_{i\in M}\mathrm{sg}(p_{\psi,i}-p_{\phi,i})^{\!\top}\ell_{\theta,i}\right],$$ (6)

where $\mathrm{sg}$ stops gradients. The prediction at each masked position depends on the other codes of the sample, so the two predictions agree only when $\theta$ ’s codes fit together. This pushes $\theta$ to coordinate its codes through the shared state $\xi$ .

##### Confidence-guided correction.

In the final part of the second phase, we add direct supervision on generated samples. For some samples in each batch, we re-mask the half of the positions with the lowest confidence $q_{\theta,i}(\hat{c}_{i}\mid y,\xi)$ , denoted $R$ , and let the frozen model complete them over several rounds into $c^{\mathrm{ref}}$ . We then train $\theta$ to predict these corrected codes from the same $(y,\xi)$ :

[Tableau] $\displaystyle\mathcal{L}_{\mathrm{gen}}$ $\displaystyle=\mathcal{L}_{\mathrm{DM}}+\lambda\,\mathcal{L}_{\mathrm{corr}},$ (7) $\displaystyle\mathcal{L}_{\mathrm{corr}}$ $\displaystyle=\mathbb{E}_{\mathrm{selected}}\!\left[\frac{1}{|R|}\sum_{i\in R}-\log q_{\theta,i}(c_{i}^{\mathrm{ref}}\mid y,\xi)\right].$

The frozen model, the auxiliary model and the correction are used only in training, so inference remains a single forward pass of $\theta$ .


##### Dense supervision.

Dense tasks are supervised with ground truth, using cross-entropy for segmentation, an $\ell_{1}$ depth error and $1-\cos$ for surface normals.


### 4 Experiments


#### 4.1 Experimental Setup


##### Data and training.

All main results use the same Jeveration checkpoint. Generation training combines FLUX-Reason-6M images [ 16 ] and Qwen-Image [ 46 ] renderings of text-to-image-2M prompts [ 59 ] . Image-to-image training uses derived conditions and synthetic style pairs, while dense tasks use NYUv2 [ 38 ] . We train rank-256 LoRA adapters for about 92k steps in the first phase and 6.7k in the second, which take about four days on a single machine with four NVIDIA RTX PRO 6000 GPUs.


##### Quality evaluation.

We evaluate text-to-image generation with GenEval [ 20 ] , DPG-Bench [ 22 ] and HPSv2.1 [ 47 ] . Image-to-image outputs are scored by how well they follow the input structure, using edge F1 or depth accuracy. Stylized outputs are compared with paired targets by PSNR. Dense prediction uses the standard NYUv2 metrics. Latency is the median of five end-to-end calls on one H200 at batch 1. Additional details are provided in the supplementary material.

> Figure 5 : Image-to-image generation on held-out examples. In each pair the left image is the input and the right image the output.


#### 4.2 Text-to-Image Generation

Jeveration produces visually coherent images with detailed textures across natural scenes, portraits, objects and artistic styles ( Figs. 1 and 4 ). The samples capture both the requested content and appearance, from the dragon inside a teacup to the stained-glass phoenix. In one forward pass, it generates a $512{\times}512$ image in 77.8 ms end to end on one H200, the fastest in Tab. 1 , and reaches 0.74 GenEval.

Among unified models, Jeveration is the fastest and achieves higher GenEval and HPSv2.1 than JanusFlow, Show-o, Show-o Turbo, MMaDA and Janus-Pro-1B. At the same 512-px resolution, it improves GenEval by 0.11 over four-step Show-o Turbo-512 while reducing latency from 94.1 to 77.8 ms. Compared with the autoregressive Janus-Pro-1B and Janus-Pro-7B, it is $98\times$ and $122\times$ faster.

Compared with generation-only models, Jeveration achieves higher GenEval than the multi-step models at the same 512-px resolution (0.74 versus 0.49 to 0.65) while being 5 to 8 times faster. It also achieves higher GenEval than SANA-Sprint 0.6B, FLUX.1-schnell and SDXL-DMD2, one-step models that generate 1024-px images. These results show that a frozen VLM can generate images of competitive quality in one forward pass.

#### 4.3 Image-to-Image and Dense Prediction


##### Image-to-image generation.

As shown in Fig. 5 , the same checkpoint handles many image-to-image tasks. It can turn edge maps and depth maps into realistic images, colorize grayscale photos, and render photos in anime, Studio Ghibli and watercolor styles. Jeveration achieves strong structural fidelity, with 0.880 HED edge F1, 0.802 depth $\delta_{1}$ and 0.937 colorization edge F1 on held-out examples ( Tab. 2 ). Within this structure, the text prompt guides the content and appearance. Notably, this control comes at almost no extra cost, since each request is still a single forward pass of 91.7 ms, only 14 ms more than text-to-image generation. These results show that controllable generation is possible in one forward pass, without iterative sampling.


##### Dense prediction.

The same checkpoint is also a strong dense predictor ( Fig. 6 ). As shown in Tab. 3 , it reaches 67.7 mIoU on NYUv2, on par with dense-only models trained from the same backbone (67.8 and 67.3), and significantly outperforms DeepLabV3+, with 14.2 higher mIoU and a 32% lower depth error (0.267 versus 0.393 m). Each prediction takes a single forward pass of about 78 ms. Surface normals lag behind, likely because fine local geometry is the most sensitive to sharing capacity across tasks. These results demonstrate that a single checkpoint can serve both image generation and dense prediction.

#### 4.4 Ablation Studies


##### Shared state and decision training.

The shared random state lets all positions follow one image, while different states give different images. Decision training teaches the model to use this state. Without it, the first-phase masked model reaches only 0.32 GenEval in one pass ( Fig. 2 ). With a fixed state instead of a random one, HPSv2.1 drops from 28.27 to 26.63 and GenEval from 0.73 to 0.70 ( Tab. 4 ). The randomness of the shared state thus makes the images more coherent and of higher quality.

##### Correction target.

The correction target brings a further gain in image quality, as removing it lowers HPSv2.1 from 28.03 to 27.92 at similar GenEval ( Tab. 4 ). This suggests that distribution matching already determines the composition, while the correction refines details.


##### Image-head branches.

In the first-phase masked model, the two branches together outperform either branch alone, with 0.64 GenEval against 0.60 and 0.59 for the wide and codebook branches ( Tab. 4 ). We hypothesize that they are complementary, as the codebook branch inherits the structure of the tokenizer’s codebook while the wide branch adds capacity beyond this structure.


##### Source conditioning.

Both the generated codes and the source image are essential for image-to-image generation. Even without the source, the decoder recovers most of the input structure from the codes alone (0.792 HED edge F1 and 0.767 depth $\delta_{1}$ ), indicating that the VLM transfers the input layout into its decisions. Feeding the source image to the decoder brings further improvements, raising HED edge F1 to 0.880 and colorization edge F1 from 0.757 to 0.937 ( Tab. 2 ). This suggests that the 128 codes capture the global structure, while the source image supplies the fine details.

##### Joint training across tasks.

Joint training extends the model to image-to-image generation and dense prediction at almost no cost to text-to-image quality. As shown in Tab. 5 , Jeveration performs on par with a model trained only on text-to-image, with comparable GenEval (0.74 versus 0.73), HPSv2.1 (28.06 versus 28.28) and DPG (78.24 versus 78.61). For dense prediction, it matches dense-only models in segmentation, with only a modest drop in depth and normal accuracy ( Tab. 3 ). This demonstrates that a single set of adapters on a frozen VLM can accommodate diverse visual tasks with little interference.


### 5 Conclusion

Jeveration introduces a third paradigm for image generation, in which a System One model returns a whole image as one joint decision in a single forward pass. Built on a frozen VLM, it conditions all code positions on a shared random state to encourage global consistency, while a masked model trained beforehand provides the target conditional distributions for parallel code prediction. One checkpoint performs text-to-image generation, image-to-image generation and dense prediction, and joint training across tasks comes at almost no cost to text-to-image quality. Jeveration generates 512-px images in 78 ms on a single H200, achieves strong structural fidelity in image-to-image generation, and delivers segmentation performance comparable to dense-only models. We expect this paradigm to extend to further visual tasks and modalities.

### 4 Implementation and Evaluation


##### Model.

Jeveration keeps the Qwen3.5-4B backbone and its vision tower frozen. All tasks share rank-256 LoRA adapters, and task-specific heads read the decision tokens. Image generation uses 128 TA-TiTok codes from an 8,192-entry codebook, and dense prediction uses 432 spatial queries. About 1.0B parameters are trainable in total, including the adapters, input modules and output heads.


##### Training.

Training has two phases, masked prediction followed by decision training with distribution matching and correction ( Tab. 1 ). We use AdamW with an EMA of 0.999 on four NVIDIA RTX PRO 6000 GPUs. The correction re-masks the 50% least confident positions of a sample, which the frozen first-phase model completes in four rounds at CFG 3, with $\lambda=1$ .

> Table 1 : Main training settings. The backbone remains frozen in every stage.

##### Decoding.

We adapt the text-aware decoder of TA-TiTok to 512 px and train it to reconstruct images from their codes. A source-conditioning branch is added for image-to-image tasks. The decoder relies on both of its inputs ( Tab. 2 ). Replacing the codes with those of another example lowers HED edge F1 from 0.896 to 0.552 and depth $\delta_{1}$ from 0.825 to 0.346, while replacing the source image lowers them to 0.652 and 0.767. This shows that the codes carry most of the structure and the source image refines it.

##### Evaluation.

For text-to-image generation, GenEval uses its 553 prompts with four samples each, HPSv2.1 uses 3,200 prompts, and DPG-Bench scores 1,064 prompts as $2\!\times\!2$ grids. For image-to-image generation, structure fidelity is measured on 341 held-out examples per task. We extract the structure from each output and compare it with that of the reference image, using HED edge F1, depth $\delta_{1}$ after scale-and-shift alignment, and Canny edge F1 for colorization. Style PSNR compares each output with its paired target on 223 held-out examples. For dense prediction, we report the standard NYUv2 metrics on the 654 test images. The dense-only models use the same backbone and initialisation as Jeveration. All latencies are end-to-end times from prompt to decoded image on one H200 at batch 1, reported as the median of five calls after two warm-up calls.
