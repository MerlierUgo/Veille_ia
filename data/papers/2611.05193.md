## Factorized MLLM Embeddings for Composed Image Retrieval

Composed Image Retrieval (CIR) aims to retrieve a target image given a reference image and a modification text. Although recent approaches leveraging Multimodal Large Language Models (MLLMs) have shown significant progress, we argue that the MLLM’s compositional understanding remains underutilized. This stems from directly mapping composed queries into a retrieval embedding via contrastive supervision alone, without explicitly resolving the intended visual modifications. In this work, we introduce Factorized MLLM Embeddings (FactEmbed), which decouples compositional query comprehension from building discriminative embeddings. Rather than directly projecting the composed query into a single embedding without internal reasoning, FactEmbed employs a set of factorized latents that simulate the intended visual modifications via an intermediate target imagination objective. This process encourages the latents to ground into target semantics before forming discriminative representations for retrieval. Subsequently, to propagate these factorized representations throughout the model for retrieval, we optimize a factor-level contrastive loss while distilling the decomposed representations into a deeper attention layer of the MLLM. Finally, for efficient inference, we retain the [EOS] token to establish a global-level embedding on top of these factorized latents, while we exploit the mean-pooled factorized latents to rerank a short candidate list at negligible cost, as both are produced by the same forward pass. Extensive evaluations demonstrate that FactEmbed outperforms prior works across CIR benchmarks.


### 1 Introduction

Composed Image Retrieval (CIR) aims to retrieve a target image from a gallery using a composed query, consisting of a reference image and a modification text [ 70 ] . CIR allows users to express their search intent through relative descriptions: they may provide an image and specify how the desired result should differ from it. This paradigm is appealing when users can recognize a desired image by its visual relation to a reference, but cannot easily describe the target itself.

Recently, Multimodal Large Language Models (MLLMs) have emerged as a powerful foundation for CIR, owing to their ability to deeply fuse visual and linguistic information within a unified autoregressive representation space [ 76 , 22 ] . A common strategy is to finetune an MLLM contrastively by compressing the multimodal query and the target image into a single embedding, typically obtained from the final [EOS] token, and directly optimizing their similarity [ 65 , 48 , 79 , 76 ] . Despite its effectiveness, this formulation exposes a key limitation: forcing a direct mapping onto a single embedding provides no explicit signal for the MLLM to exploit its compositional understanding capability to resolve the requested edit before forming a discriminative embedding.

To overcome this, we aim to decouple query comprehension from discriminative embedding learning, allowing the model to first simulate the requested edit, i.e . , imagine the target, and then build its retrieval embedding upon the imagined target. We present FactEmbed, which realizes this intermediate step through a compact set of factorized latents that parse the query before producing the final embedding. These factorized latents are prepended to the [EOS] token in the input sequence, serving as information bottlenecks that decompose fused multimodal queries into factor-level components. This explicit decomposition enables FactEmbed to isolate specific visual attributes and distinguish the factors the text modifies from those it preserves, in contrast to direct contrastive mapping which only implicitly infers the modified embedding. To encourage each latent to capture different details in the target image, we adopt a target imagination objective parameterized by a lightweight decoder over these latents. Given a coarse layout prior of the target, the latents are trained to imagine the residual fine-grained factors that the prior cannot explain. Constraining reconstruction through these bottlenecks forces the latents to cluster semantically coherent target factors to maximize the coverage. This provides structural supervision without requiring explicit reasoning traces or dense annotations, thereby allowing the model to implicitly simulate the specified edit.

Reconstruction alone, however, shapes the latents generatively without ensuring their utility for retrieval: paired query and target could be faithfully decomposed yet embedded in incompatible coordinate spaces. We address this by adapting target imagination for retrieval in two ways. First, we apply a factor-level InfoNCE objective directly on the factorized latents, ensuring that the decomposed factors are aligned for retrieval rather than only for reconstruction. Second, we distill the decoder’s factorized representation into the attention maps of the latents at a deeper layer, transferring the fine-grained decomposition from the auxiliary head into the backbone layers accessed during retrieval.

Lastly, we assign complementary roles to the two outputs produced in a single forward pass. Positioned prior to the [EOS] , the factorized latents allow [EOS] to integrate the decomposed factors into a global retrieval embedding, while [EOS] is optimized as a single retrieval embedding for efficient retrieval. Yet, as fine-grained information is inevitably diluted when aggregating multiple factors into a single discriminative embedding, we rerank a short candidate list retrieved by [EOS] using the mean-pooled latents. This complementary structure allows FactEmbed to achieve fast global recall via single [EOS] token while precision is significantly boosted by recovering fine-grained factor evidence during reranking. Because both representations originate from a single forward pass and the mean-pooled latent adds only one vector per image, this design complements the global embedding with factor-level evidence without additional encoding or heavy storage overhead. Combined with our MLLM data augmentation, FactEmbed achieves state-of-the-art results on CIR benchmarks, outperforming both CIR methods and general-purpose embedding models.


### 2 Related Work

Composed Image Retrieval. CIR aims to retrieve a target image from a gallery given a reference image with a modification text that states how the desired result should differ from it [ 70 , 49 , 51 , 12 ] . Earlier works [ 2 , 70 , 8 , 73 , 72 , 23 ] attempted to resolve representational conflict by performing the composition inside CLIP [ 58 ] or BLIP [ 34 , 33 ] embeddings. Then, since collecting high-precision annotations for CIR incurs significant cost [ 78 , 18 ] , two parallel lines of research have been actively explored: learning with noisy CIR annotations [ 6 ] and zero-shot approaches [ 59 ] . While the former stream attempted to mitigate the impact of noisy annotations by leveraging loss dynamics [ 37 ] , similarity curves [ 29 ] , MLLM-constructed anchor set [ 10 ] , or unlearning process [ 41 ] , zero-shot approaches aim to bypass the high cost of collecting annotated triplets [ 21 , 3 , 13 , 26 , 39 , 66 ] . Notably, recent zero-shot methods also anticipate the target, either by generating a proxy image [ 39 ] or by leveraging a world model [ 66 ] ; in contrast, our imagination is embedded within the embedding model itself, requiring neither a generative model nor an additional inference pass.

More recently, LLMs and MLLMs have been widely adopted in CIR owing to their strong comprehension capabilities. CIR-LVLM [ 65 ] adapted a local MLLM for CIR by introducing intent-aware instructions with learnable soft prompts, while ReCALL [ 76 ] proposed MLLM-based triplet augmentation strategy by diagnosing the blind spots of adapted MLLM retriever. To further exploit the comprehension capability of LLMs, CCIN [ 67 ] and FIRE-CIR [ 11 ] incorporated an external LLM at query time to decompose the query at the attribute level, which, however, incurs substantial inference overhead, with FIRE-CIR further requiring verification linear in the number of candidates. Thus, in this work, we adapt a local MLLM to exploit its inherent comprehension capability; whereas prior MLLM-based methods [ 65 , 76 ] directly map the composed query onto a single embedding, we encourage the model to decompose the query within a single forward pass and build the retrieval embedding on top of the decomposed factors.

Multimodal Retrieval with MLLMs. MLLM embeddings are being extensively studied in multimodal retrieval where complex comprehension is required [ 52 , 80 , 35 ] . VLM2Vec [ 25 ] initially used the last hidden state of the [EOS] token of a causal MLLM. Yet, as [EOS] is not designed to generate embeddings, different methods are being studied, e.g. , mean-pooling [ 31 , 69 , 38 ] and multi-vector embeddings [ 44 , 27 , 9 ] . Also, integrating computation via explicit reasoning [ 16 ] , latent rollouts [ 17 ] , or reinforcement-learned generative embeddings [ 30 ] is another prominent line of research. Our work resembles the stream of appending a small bank of learned tokens whose hidden states become the representation [ 75 , 64 ] . None of these works, however, constrains what an individual token should represent. In contrast, we leverage target reconstruction as a structural supervisory signal, forcing each factorized latent to ground and specialize in spatially coherent regions of the target scene.

To enforce structured factorization without requiring dense annotations, we attach a decoder to an intermediate MLLM layer, which utilizes these latents as an information bottleneck to reconstruct target patch features via a target imagination objective. In addition, we apply a factor-level InfoNCE to the resulting latents $\{u_{k}\}_{k=1}^{K}$ to leverage the decomposed factors for retrieval, while global-level embedding $z$ is trained with the instance-level InfoNCE objective.

Compact Latent Representations. Representing an input as a small set of latents has been studied extensively across fields. Retrievers used it for late interaction [ 32 , 53 , 42 , 36 ] , Perceiver [ 20 , 19 ] exploited latents to decouple compute from input size, DETR [ 4 ] used them as object queries to perform object detection, and slot attention [ 50 , 60 , 61 ] utilized slots to decompose the scene into object-wise regions by normalizing the attention across latents. FactEmbed adopts the same competitive normalization in its decoder to induce factor-level specialization, but keeps the MLLM’s forward pass intact, thereby preserving kernel optimizations such as FlashAttention [ 7 ] .


### 3 FactEmbed: Factorized MLLM Embeddings

Task. Given a query $q=(I_{r},T)$ consisting of a reference image $I_{r}$ and a modification text $T$ , the goal of Composed Image Retrieval (CIR) is to retrieve the target image $t=I_{t}$ that depicts the reference after the described modification. The task is intrinsically compositional: the model must decide which visual factors of $I_{r}$ the text modifies ( e.g . , “replace the logo on the shirt”) and which it must preserve ( e.g . , the rest of the shirt and the background), then express the result of that edit as a retrievable representation.

Overview. As shown in Fig. 1 , FactEmbed adapts an MLLM to produce CIR embeddings, utilizing a shared backbone to encode both the multimodal query and the target image. Rather than mapping the input directly to a single vector, we first introduce $K$ learnable factorized latents into the multimodal input, on top of which the [EOS] embedding is formed. This provides the model with the capacity to represent the complex query as a structured set of compositional components. To ground these latents in the visual content of the target image, we train them to reconstruct the target’s patch features beyond a coarse layout prior, a process we refer to as target imagination. We perform this reconstruction by attaching a lightweight decoder at an intermediate layer of the MLLM, which allows the deeper layers to transform the decomposed factors into discriminative representations for retrieval. For retrieval training, we apply InfoNCE [ 5 ] at two levels: a factor-level loss encourages the factorized latents to contribute to retrieval by matching the query and target latents via optimal transport, while an instance-level loss optimizes the global embedding. In this way, the imagined decomposition propagates fine-grained evidence into a compact embedding that remains efficient for retrieval.


#### 3.1 Factorized Latents with Target Imagination

Motivation. CIR requires modifying specific visual concepts given text instructions ( e.g. , replacing an item). However, directly mapping a composed query to a global embedding in an MLLM provides no explicit mechanism for disentangling the visual attributes to be modified from those that should remain invariant. To overcome this, we introduce a compact set of factorized latents whose explicit job is to parse the scene into structured factors. By decomposing the representation, these latents are designed to give the model room to express the instructed modification on the relevant factors without distorting the others.

Factorized Latents. Factorized latents are defined as a set of $K$ learnable tokens, $\mathbf{U}^{(0)}\in\mathbb{R}^{K\times D}$ , which act as information bottlenecks to parse multimodal inputs into factorized representations. These tokens are prepended to the [EOS] in both the query and target sequences and interact with the multimodal inputs via the MLLM’s causal attention. We denote their hidden states at layer $\ell$ by $\mathbf{U}^{s,(\ell)}=[u^{s,(\ell)}_{1},\dots,u^{s,(\ell)}_{K}]$ for $s\in\{q,t\}$ , where $s$ indicates the query- or target-side input, and drop the layer index for the last layer, i.e . , $\mathbf{U}^{s}$ .

Lightweight Decoder for Imagination. For target imagination, we employ a lightweight decoder parameterized by a self-attention layer and 3-layer MLP attached to an intermediate layer $\ell$ ( $\ell=14$ out of 28 layers by default) of the MLLM to reconstruct the target patch representation from a vision foundation model [ 56 ] . Note that we omit the superscript $s$ for brevity since the decoder is applied to each side independently. Each 1D factorized latent $u^{(\ell)}_{k}\in\mathbb{R}^{D}$ is spatially broadcast across a 2D grid with learnable positional embeddings and passed through the decoder. Yet, reconstructing the target from the latents alone would force them to encode the global layout of the target, which is dominated by low-frequency signals (often irrelevant to the localized edits in CIR). Thus, we condition the decoding process on a layout prior that provides only the coarse layout of the target; ground-truth (GT) target features $F\in\mathbb{R}^{H\times W\times D_{\textrm{DINO}}}$ are average-pooled to $h\times h$ , expanded back to full resolution, and added to the broadcast latents. As this layout prior already explains the coarse layout, minimizing the reconstruction error drives the latents to carry only the information that is not contained in the coarse layout. Consequently, for each latent $k$ , the decoder predicts spatial logits $\mathcal{M}_{k}\in\mathbb{R}^{H\times W}$ along with reconstruction features $\hat{F}_{k}\in\mathbb{R}^{H\times W\times D_{\text{DINO}}}$ , where we index the $HW$ spatial positions by $p$ . To ensure that the contributions of all latents sum to 1 at each position $p$ , we obtain the normalized alpha mask $\bar{\mathcal{M}}_{k}$ via a softmax over the latent dimension:

[Tableau] $$\bar{\mathcal{M}}_{k,p}=\frac{\exp(\mathcal{M}_{k,p})}{\sum_{k^{\prime}=1}^{K}\exp(\mathcal{M}_{k^{\prime},p})}.$$ (1)

Then, the reconstructed feature is formed by the mask-weighted sum:

[Tableau] $$\hat{F}=\sum\nolimits_{k=1}^{K}\bar{\mathcal{M}}_{k}\odot\hat{F}_{k},$$ (2)

where $\odot$ is element-wise multiplication with broadcasting along the channel dimension. Let $\hat{F}^{q}$ and $\hat{F}^{t}$ denote the features predicted from the query- and target-side latents, respectively. Both are supervised against the same GT target features $F$ , and the imagination loss is the mean squared error averaged over both sides:

[Tableau] $$\mathcal{L}_{\mathrm{imag}}=\frac{1}{2}\sum\nolimits_{s\in\{q,t\}}\text{MSE}(\hat{F}^{s},F).$$ (3)

As the coarse target layout prior is shared by both sides, $\mathcal{L}_{\mathrm{imag}}$ is minimized only by improving the residual details that are not covered by the layout prior. On the query side, the latents must infer this residual from $(I_{r},T)$ without observing the target, which is the component we refer to as imagination. On the target side, the same objective anchors the target latents to the same residual factors, so that query and target latents occupy comparable factor slots for the latent matching in Sec. 3.2 .


#### 3.2 From Imagination to Retrieval

Factor-level Matching. To explicitly involve the factorized latents in retrieval, we apply an InfoNCE [ 5 ] on top of them. Building upon the factor alignment established by $\mathcal{L}_{\mathrm{imag}}$ , we define the matching score $s_{\mathrm{OT}}(\mathbf{U}^{q},\mathbf{U}^{t})$ using Sinkhorn optimal transport (OT) over pairwise cosine similarities to allow flexible factor-to-factor correspondences (see Appendix E ). For the $i$ -th query and $j$ -th target in a batch of size $B$ , the factor-level similarity is $\mathbf{S}^{f}_{ij}=s_{\mathrm{OT}}(\mathbf{U}^{q}_{i},\mathbf{U}^{t}_{j})$ . With the batch-wise contrastive loss over a similarity matrix $\mathbf{S}\in\mathbb{R}^{B\times B}$ defined as:

[Tableau] $$\mathcal{C}(\mathbf{S})=-\frac{1}{B}\sum_{i=1}^{B}\log\frac{\exp(\mathbf{S}_{ii}/\tau)}{\sum_{j=1}^{B}\exp(\mathbf{S}_{ij}/\tau)},$$ (4)

applying $\mathcal{C}(\mathbf{S}^{f})$ encourages each query factor to align with its counterpart in the target, which a single pooled vector cannot enforce. $\tau$ is a temperature parameter.

Instance-level Matching. The [EOS] token, which attends to the factorized latents, aggregates the comprehended factors into a single embedding. We read out its normalized hidden state as the global embedding $z$ and apply the same contrastive loss $\mathcal{C}(\mathbf{S}^{g})$ with the instance-level similarity $\mathbf{S}^{g}_{ij}=z_{i}^{q\top}z_{j}^{t}$ between the $i$ -th query and the $j$ -th target. Unlike the factorized set, which requires storing $K$ vectors per target image, $z$ remains a single vector and thus serves as the primary retrieval embedding at scale. Our retrieval objective thus combines both levels:

[Tableau] $$\mathcal{L}_{\mathrm{NCE}}=\mathcal{C}(\mathbf{S}^{f})+\mathcal{C}(\mathbf{S}^{g}),$$ (5)

where $\mathcal{C}(\mathbf{S}^{f})$ aligns individual factors through OT and $\mathcal{C}(\mathbf{S}^{g})$ directly optimizes the embedding used at test time.

Propagating Factorization into the MLLM Backbone. While intermediate-layer decoding effectively encourages latent specialization, deeper layers near the retrieval output tend to lose spatial decomposition as representations abstract into global embeddings. To preserve factorized knowledge within the MLLM backbone, we distill the spatial alpha masks $\bar{\mathcal{M}}$ generated by the decoder into the latent-to-patch attention of the factorized latents at a deeper layer. Note that we formulate the spatial distillation loss exclusively on the target-side forward pass, as the query-side attention maps are defined over the reference image space, which does not share a spatial grid with the target alpha masks. Specifically, let $\mathcal{A}_{k}\in\mathbb{R}^{H\times W}$ denote the head-averaged attention of the $k$ -th factorized latent toward the target patch tokens at layer $\ell_{\text{top}}$ , with the softmax taken over the patch keys only, bilinearly resampled to the decoder grid. Then, we normalize $\mathcal{A}_{k}$ and $\bar{\mathcal{M}}_{k}$ over the spatial positions into distributions $\mathbf{a}_{k}$ and $\mathbf{m}_{k}$ , each describing the region the $k$ -th latent occupies:

[Tableau] $$\mathbf{a}_{k,p}=\frac{\mathcal{A}_{k,p}}{\sum_{p^{\prime}}\mathcal{A}_{k,p^{\prime}}},\quad\mathbf{m}_{k,p}=\frac{\bar{\mathcal{M}}_{k,p}}{\sum_{p^{\prime}}\bar{\mathcal{M}}_{k,p^{\prime}}}.$$ (6)

Consequently, we formulate a spatial distillation loss using Kullback-Leibler (KL) divergence to align the deeper layer attention distributions with the decoder’s spatial alpha masks:

[Tableau] $$\mathcal{L}_{\mathrm{distill}}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{KL}\big(\mathbf{m}_{k}\,\|\,\mathbf{a}_{k}\big).$$ (7)

This explicitly transfers spatial decomposition from the decoder to the MLLM. Although the supervision is applied only on the target side, it shapes the backbone and the latents shared by both sides, thereby encouraging the query-side latents to also retain localized semantics at inference, where the target layout prior is unavailable.

#### 3.3 Training Objective and Inference

Training. Our joint objective reconciles two competing dynamics: $\mathcal{L}_{\mathrm{imag}}$ forces factorized latents to partition target features into disjoint factors, whereas $\mathcal{L}_{\mathrm{NCE}}$ encourages latents within an instance to collapse into a single discriminative embedding [ 54 ] . To address this, we employ a staged learning strategy. In Stage 1, we optimize only the reconstruction loss $\mathcal{L}_{\mathrm{imag}}$ to warm up the factorized latents and the decoder, establishing a stable factorized prior by mapping latents to a spatially coherent region of the target scene. In Stage 2, we further train the MLLM backbone with DoRA [ 46 ] adapters, jointly with the latents and the decoder, using full objective:

[Tableau] $$\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{NCE}}+\lambda_{\mathrm{imag}}\mathcal{L}_{\mathrm{imag}}+\lambda_{\mathrm{distill}}\mathcal{L}_{\mathrm{distill}},$$ (8)

where $\lambda_{\mathrm{imag}}$ and $\lambda_{\mathrm{distill}}$ are coefficients. Finally, we follow ReCALL [ 76 ] to add a post-training stage which integrates MLLM-augmented triplets to reduce false negatives [ 11 , 29 ] and mitigate the influence of mislabeled triplets [ 37 , 41 , 6 ] , both of which stem from the sparse supervision of CIR datasets. In brief, we adopt the existing augmentation pipeline to generate modification texts between each reference image and its mined hard negatives; the difference from [ 76 ] is that we condition the MLLM on the original target image and prompt it to describe what distinguishes the hard negative, which yields captions non-redundant with the original modification text in a single generation pass. Details on the augmentation are in Appendix F .

Inference. During inference, a single forward pass yields both global embedding $z$ and factorized latents $\{u_{k}\}_{k=1}^{K}$ . To minimize the memory footprint and computational cost, we aggregate latents into a single mean vector $\tilde{u}=\frac{1}{K}\sum_{k=1}^{K}u_{k}$ , and utilize it exclusively for efficient reranking. Note that $\tilde{u}$ is not explicitly optimized during training; rather, it serves as a compact proxy for the factorized set, whose members are aligned via OT, and thus requires no additional training. Specifically, candidates in the gallery are initially searched with $z$ alone, and the top-100 candidate shortlist is reranked by integrating the cosine similarity of the mean factor as:

[Tableau] $$r(q,t)=\cos\big({z}^{q},{z}^{t}\big)+\cos\big(\tilde{u}^{q},\tilde{u}^{t}\big).$$ (9)

Since only the top candidates are rescored with a single vector, the additional cost is negligible and independent of the gallery size, while still leveraging the factor-level evidence.

### 4 Experiments

Datasets & Metrics. We test FactEmbed on CIRR [ 49 ] and FashionIQ [ 74 ] , two standard CIR benchmarks. However, as original benchmarks contain ambiguous samples [ 18 ] and fail to provide robust evaluation [ 47 ] , we conduct our primary evaluations on Refined-CIRR and Refined-FashionIQ [ 18 ] . Results on original datasets are also reported. For evaluation metrics, we use Recall@ $N$ (R@ $N$ ), the fraction of queries whose target appears in the top- $N$ results. Along with standard Recall, we also report Recall ${}_{\mathrm{subset}}@\{1,2,3\}$ on CIRR, which are computed within each query’s curated six-candidate subset.

Implementation Details. Adopting the base setup from ReCALL’s repository [ 76 ] , we use DoRA [ 46 ] to finetune Qwen2.5-VL-7B-Instruct [ 1 ] with rank $16$ , scaling factor $64$ . We use AdamW optimizer, a cosine schedule with $10\%$ warmup, a batch size of 512, and bfloat16 mixed precision. The last checkpoint is used for evaluation. For hyperparameters, we set the number of latents $K=8$ , the resolution of target layout prior to $2\times 2$ ( $h=2$ ), and the decoding layer to $\ell=14$ . Additionally, we distill the factorized map into the attention map from the 3rd layer from the top ( $\ell_{\text{top}}=-3$ ). Loss coefficients are set to $\lambda_{\mathrm{imag}}\!=\!1.0$ and $\lambda_{\mathrm{distill}}\!=\!0.5$ for all experiments.


#### 4.1 Main Results

In Tab. 1 , we benchmark FactEmbed on refined CIR benchmarks against recent CIR methods and general-purpose embedding models [ 25 , 52 , 43 , 35 , 63 , 45 ] using their official checkpoints. While prior works primarily relied on broader metrics like Recall@5 on CIRR due to sample ambiguities in original benchmarks, we emphasize that Recall@1 and Subset Recall@1 on CIRR serve as more precise ranking metrics under these refined evaluation settings, where broader metrics saturate near top performance. Specifically, FactEmbed outperforms two strong baselines, CSMCIR [ 57 ] (which additionally relies on synthetic text captions for every gallery image) and ReCALL [ 76 ] : it achieves improvements of 2.7% and 2.3% in Recall@1 on Refined-CIRR, and 2.3% and 2.4% in average Recall@10 on Refined-FashionIQ, respectively. These gains demonstrate the advantage of decoupling complex query understanding from direct visual alignment: our decomposed factorized latents yield fine-grained, disambiguated semantic representations that standard contrastive architectures do not explicitly encourage.

In Tab. 3 and Tab. 3 , we further report performance on the original CIRR and FashionIQ datasets. Notably, all methods score substantially lower on the original benchmarks than on their refined counterparts. This is consistent with prior findings [ 18 , 47 ] that the original benchmarks contain ambiguous annotations and evaluation artifacts, which may underestimate the compositional reasoning capabilities of high-capacity models. #### 4.2 Forming Embeddings with Factorized Latents

As factorized latents can be turned into a retrieval score in several ways, we compare the variants in Tab. 4 . Matching the full latent set via OT (“Full Factor”) achieves the highest R@1 on both benchmarks, but requires storing $K$ vectors per gallery image, whose storage and search costs grow with the gallery size [ 27 , 9 ] . Among single-vector alternatives, the mean-pooled latents (“Mean Factor”) [ 45 ] perform the worst, as $\tilde{u}$ is never directly optimized for retrieval, leaving $\tilde{u}$ less discriminative as a standalone global embedding. Yet, directly optimizing $\tilde{u}$ with the instance-level objective in place of [EOS] (“Mean Factor # ”) still falls behind [EOS] in R@1 on both benchmarks, suggesting that imposing instance-level objective on the latents pulls them toward a single discriminative embedding at the cost of fine-grained evidence. We therefore keep the latents factor-aligned and use [EOS] as the global embedding for initial retrieval, while exploiting $\tilde{u}$ as complementary factor-level evidence for reranking. This efficient reranking narrows the R@1 gap to Full Factor to 0.24 and 0.21, with only two vectors per gallery image, a memory footprint on par with standard multi-vector CIR methods [ 41 , 37 , 67 , 29 , 2 ] .


#### 4.3 Ablation Study

In Tab. 5 , we conduct component ablation study. Introducing factorized latents with the target imagination alone (b) does not consistently improve retrieval: while it improves R@10 on FashionIQ and Refined-FashionIQ by 1.00 and 1.16, and R@5 on CIRR by 0.99, it slightly lowers R@1 on CIRR. We attribute this to the gap between generation and discrimination: target reconstruction structures the latents into semantically factorized components, which already benefits FashionIQ where modifications are confined to localized attributes, but it provides no explicit alignment metric for ranking, so the decomposition alone is insufficient for precise top-1 retrieval on open-domain CIRR. Yet, as it lays a robust foundation for fine-grained query decomposition, we find that bridging the gap with factor-level InfoNCE (c) and incorporating the attention distillation loss (e) effectively enhances the retrieval performance by transferring localized decomposition into the MLLM’s deeper attention layer. Subsequently, incorporating our ERR in (f) delivers a prominent gain of 1.17 and 0.97 in Avg. on CIRR and Refined-CIRR, respectively. In contrast, applying the same reranking to latents trained without any auxiliary objective changes Avg. by only $-0.37$ and $+0.24$ , indicating that the gain does not stem from merely fusing an additional vector but from the structure imposed by our objectives. We note that this gain comes at a marginal computational overhead, as the factorized latents are generated within the same forward pass (see Appendix C ). Lastly, integrating the post-training stage (h) achieves additional gains, demonstrating the effectiveness of mitigating the noise arising from the sparse supervision of CIR datasets. To verify that these gains are not attributed to the augmentation alone, we also apply the post-training stage directly to the baseline (g). While post-training alone improves the baseline, our full model (h) further surpasses it by 2.91 and 2.57 in R@1 on CIRR and Refined-CIRR, and by 2.87 and 2.37 in R@10 on FashionIQ and Refined-FashionIQ, respectively. Also, the gains of our components remain comparable with and without post-training ((a) $\rightarrow$ (f) vs. (g) $\rightarrow$ (h)), indicating that FactEmbed and augmentation are complementary. Results of post-training with ReCALL’s augmented data are provided in Fig. 6 .

#### 4.4 Analysis and Discussion

Imagination Layer Selection. Determining the MLLM layer $\ell$ for target imagination governs a trade-off; when the decoder is attached too early, the factorized latents may lack sufficient contextual fusion of multimodal inputs to imagine the target, while attaching it too late leaves insufficient subsequent layers to transform the decomposed factors into a discriminative retrieval embedding. In Fig. 2(a) , we evaluate decoder placements at layers $\ell\in\{7,14,21\}$ of the 28-layer MLLM, and find that $\ell=14$ yields the best result, which aligns with recent findings [ 24 , 77 ] .

Impact of Target Imagination. To isolate the effect of target imagination, we compare against variants that train the latents solely with InfoNCE, matched by either maximum similarity (MS) [ 75 ] or OT, in Fig. 2(b) . While these variants outperform the naïve baseline, we observe that target imagination brings a further gain by enforcing the latents to decompose and structure the target scene rather than relying on the contrastive signal alone. Also, OT matching consistently outperforms MS matching strategy on both benchmarks, supporting our choice of OT for factor-level matching.

What Does the Decoder Imagine? Fig. 3 compares the imagined features $\hat{F}^{q}$ against the GT target features $F$ , using joint PCA basis. On the query side, the imagined features reconstruct the overall structure of the target: while the layout prior supplies only the coarse layout, the factorized latents recover fine-grained details such as object silhouettes. The rightmost column visualizes $\arg\max_{k}\bar{\mathcal{M}}_{k,p}$ , demonstrating that each factorized latent contributes to reconstructing semantically coherent regions. This suggests that each latent specializes in a coherent semantic factor of the target. Additional visualizations are in Appendix A .

Impact of Target Layout Prior. As described in Sec. 3.1 , the decoder is conditioned on a coarse target layout prior. Fig. 4 visualizes the decomposition under different prior resolutions. Without the layout prior, the latents must also encode the global layout, which dominates the reconstruction objective and causes them to collapse into a few coarse regions. In contrast, when the prior is injected, we found that the factorized latents are encouraged to focus on fine-grained visual structures, decomposing the target into localized parts such as arms, legs, and necklines. We set $h=2$ so that the layout prior provides only the coarse layout while leaving the localized factors to the latents.

Generalization across Backbones. We further apply FactEmbed to stronger MLLM backbones in Tab. 6 . Specifically, we observe that upgrading the backbone from Qwen2.5-VL-7B to Qwen3-VL-8B improves R@1 by 2.65 points on the CIRR test set, exceeding the 1.60 points gain reported by ReCALL [ 76 ] for the same backbone transition. This demonstrates that FactEmbed scales more effectively with improved backbone capabilities. The performance gains further extend to Qwen3-VL-Embedding-8B, a backbone already specialized for retrieval, where FactEmbed achieves top performance across most metrics.


### 5 Conclusion

In this work, we present FactEmbed, a framework that better exploits the MLLM’s compositional understanding capability to simulate visual edits by decoupling compositional query comprehension from learning discriminative embedding. To structure query comprehension, we prepend factorized latents that act as an information bottleneck, trained to imagine the residual target factors beyond a coarse layout prior that groups semantically coherent visual factors of the target without dense annotations. We then bridge generative imagination and discriminative retrieval by optimizing a factor-level InfoNCE loss via optimal transport and distilling the decoder’s alpha masks into the MLLM’s deeper attention maps. At inference, the [EOS] token serves as a global-level embedding to perform initial retrieval, while the mean-pooled factorized latents, produced in the same forward pass, rerank a short candidate list at negligible cost. Extensive evaluations show that FactEmbed achieves state-of-the-art performance, suggesting that factor-level supervision on top of instance-level matching improves MLLM-based CIR.

### Appendix B Diversity of Factorized Latents

To analyze whether each factorized latent specializes in distinct concepts, we examine the cosine similarity between factorized latents both within the same instance and across different instances (Tab. 7 ). Specifically, we compare our approach against two baseline variants: one where learnable latents are prepended to the [EOS] token without additional constraints, and another where the factor-level InfoNCE objective is introduced.

As discussed in Sec. 3.3 , applying the factor-level InfoNCE alone without the imagination objective $\mathcal{L}_{\mathrm{imag}}$ (b) increases the similarity among latents within each instance, causing them to collapse into a single instance-level representation. This is because the retrieval objective only requires the latents to be collectively discriminative across instances, providing no incentive for individual latents to take on distinct roles. Furthermore, this representation collapse becomes even more pronounced when the per-latent mean vector (computed across the dataset) is subtracted from each latent, indicating that the latents share instance-specific rather than factor-specific information. In contrast, incorporating our imagination and distillation objectives (c) yields the lowest within-instance similarity, with a clear margin after removing the per-latent mean (0.548 vs. 0.599 and 0.841). This indicates that our framework encourages the latents to take on distinct roles, whereas naïvely employing multi-vector latents with a retrieval objective drives them toward a shared representation.

Note that the latents without any auxiliary objective (a) also exhibit low within-instance similarity. We attribute this phenomenon to the fact that the latents are orthogonally initialized and largely retain this initial bias due to the lack of direct supervision. Indeed, these latents do not benefit retrieval: even with efficient reranking, they achieve an average of 73.21 on Refined-CIRR and 79.60 on the CIRR test set, falling below the baseline without latents (74.65 and 79.80), where the averages follow Tab. 1 and Tab. 3 , i.e . , (R@1 + R ${}_{\text{subset}}$ @1)/2 and (R@5 + R ${}_{\text{subset}}$ @1)/2, respectively. In contrast, under the same setting without post-training, our latents raise these scores to 76.05 and 82.35 (Tab. 5 (f)), confirming that they are not only distinct but also informative for retrieval.

### Appendix C Inference Cost

A natural concern with multi-vector representations is that they trade retrieval quality for memory footprint and query latency [ 27 , 75 ] . To address this, Tab. 8 quantifies the inference overhead on the CIRR validation set (2,297 gallery images) using a single NVIDIA RTX PRO 5000 Blackwell GPU. Crucially, the forward pass of the query encoder dominates the end-to-end latency pipeline, requiring 353ms per query at batch size 1 and an average of 164ms per query at batch size 32. In contrast, scoring the gallery using only the [EOS] embedding requires only 0.06ms per query. Our efficient reranking procedure, which re-scores the top-100 shortlist with the sum of the cosine similarities from each [EOS] and mean factorized vector, adds one extra vector per image to the index and 0.17ms per query at batch size 1 (0.003ms amortized), which only induces less than 0.05% overhead on the total latency. We adopt this design as our default inference configuration, as its storage footprint remains comparable to, or slightly smaller than that of recent CIR methods that maintain multi-vector galleries [ 41 , 37 , 67 , 29 , 23 , 2 ] . When storage and compute budgets permit, however, the full latent variant can be preferred, as full OT matching offers slightly higher R@1 (Tab. 4 ). Note that its time overhead remains marginal at the scale of the CIRR validation gallery, but both its storage ( $K$ vectors per image) and its scoring cost grow linearly with the gallery size, whereas efficient reranking only rescores a fixed top-100 shortlist.


### Appendix D Additional Implementation Details

In this section, we elaborate additional implementation details. While we use base learning rates of $2\times 10^{-5}$ and $4\times 10^{-5}$ to train DoRA modules attached to the pretrained backbone parameters for CIRR and Fashion-IQ, respectively, we apply $4\times 10^{-4}$ as the learning rate to modules such as the factorized latent and imagination decoder since our newly introduced components are trained from scratch. For the training schedule, we use 3,000, 500, and 350 steps across the three stages for CIRR, and 3,000, 350, and 350 steps for FashionIQ. While Stage 1 could technically be trained jointly with the later stages, the competing dynamics between $\mathcal{L}_{\mathrm{imag}}$ and $\mathcal{L}_{\mathrm{NCE}}$ slow down the formation of factorized latents, requiring substantially longer training to converge. Isolating Stage 1 to train only the decoder and the latents with $\mathcal{L}_{\mathrm{imag}}$ removes this competition and further allows bypassing the upper layers of the MLLM backbone, yielding a substantially more compute-efficient setup: Stage 1 completes in approximately 13 hours on 4 $\times$ RTX PRO 5000 Blackwell GPUs. Then, subsequent training stages were conducted using 2 $\times$ RTX PRO 6000 Blackwell GPUs using PyTorch FSDP. Images are resized within the processor to between $3{,}136$ and $147{,}456$ pixels, with input sequences truncated at $512$ tokens.


### Appendix E Optimal Transport for Matching Score between Factorized Sets

To measure the similarity between two unordered factorized sets, we used Optimal Transport (OT) to find the best possible alignment between them. Given the query and target factorized latents $\mathbf{U}^{q}=[u^{q}_{1},\dots,u^{q}_{K}]$ and $\mathbf{U}^{t}=[u^{t}_{1},\dots,u^{t}_{K}]$ , we first compute a pairwise cosine similarity matrix $\mathbf{R}\in\mathbb{R}^{K\times K}$ , where $\mathbf{R}_{k,m}=\cos(u^{q}_{k},u^{t}_{m})$ is the cosine similarity between the $k$ -th query factor and the $m$ -the target factor. Based on this similarity matrix $\mathbf{R}$ , the OT matching score is defined as:

[Tableau] $\displaystyle s_{\mathrm{OT}}(\mathbf{U}^{q},\mathbf{U}^{t})=\big\langle\mathbf{P}^{\star},\mathbf{R}\big\rangle,$ (10) $\displaystyle\mathbf{P}^{\star}=\arg\max_{\mathbf{P}\in\Pi(\frac{1}{K}\mathbf{1},\frac{1}{K}\mathbf{1})}\big\langle\mathbf{P},\mathbf{R}\big\rangle+\varepsilon\mathcal{H}(\mathbf{P}),$

where $\mathbf{P}^{\star}$ is the optimal transport plan that maximizes the overall alignment score and $\langle\cdot,\cdot\rangle$ denotes the Frobenius inner product. $\Pi(\tfrac{1}{K}\mathbf{1},\tfrac{1}{K}\mathbf{1})$ denotes the set of transport plans whose rows and columns each sum to $1/K$ , so that every query and target factor contributes equally. The entropy regularization $\mathcal{H}(\mathbf{P})=-\sum_{k,m}\mathbf{P}_{k,m}\log\mathbf{P}_{k,m}$ allows $\mathbf{P}^{\star}$ to be computed efficiently with a few Sinkhorn iterations, serving as a differentiable surrogate for one-to-one matching. We set the $\varepsilon=0.1$ and run 30 Sinkhorn iterations. Since the elements of $\mathbf{P}^{\star}$ sum to 1, $\langle\mathbf{P}^{\star},\mathbf{R}\rangle$ represents the average matching score in $[-1,1]$ , which is subsequently used as the factor-level similarity $\mathbf{S}^{f}$ in the first term of Eq. 5 . This encourages the factorized set of a query to align with that of its target while repulsing the sets of non-matching targets.


### Appendix F Post-training with MLLM Augmentation

A typical challenge in CIR is that the modification text often underdetermines the target image. In other words, instructions are often rarely exhaustive; they specify what should change while leaving everything else implicit. Consequently, a single composed query can often be satisfied by multiple candidate images in the gallery. To address this, prior works have leveraged LLM/MLLMs to sharpen the query itself to disambiguate the instruction [ 67 , 11 ] , enlarged the clean paired triplets [ 78 , 80 , 18 , 76 ] . Similarly, we follow ReCALL [ 76 ] to augment training triplets by pairing each reference image with its mined hard negative instances, and then finetune the model on the resulting data (comprising the reference image, its hard negative, and a generated modification text). Operating on FactEmbed after Stage 2, our augmentation pipeline consists of two phases: hard negative mining and contrastive captioning. During the mining phase, we follow ReCALL to extract hard negative instances $I_{h}$ for each reference image $I_{r}$ that ranks above the ground truth $I_{t}$ , which are then passed to the contrastive captioning phase.


#### F.1 Contrastive Captioning

Following ReCALL [ 76 ] , we convert each mined hard negative $I_{h}$ into a new positive triplet $(I_{r},\acute{T},I_{h})$ , where an MLLM writes a minimal modification text $\acute{T}$ that transforms $I_{r}$ into $I_{h}$ . In practice, however, we found this pipeline to be both noisy and costly. Since mined hard negatives frequently serve as valid targets for $(I_{r},T)$ themselves and the captioner observes only $I_{r}$ and $I_{h}$ , we observed that the captioner has no cue to separate $I_{h}$ from $I_{t}$ . As a result, it often returned $T$ unchanged, producing duplicate queries with conflicting positives (9% and 11% of the samples that survived ReCALL’s VQA filter on CIRR and FashionIQ). This pipeline was also inefficient: the local MLLM captioner frequently violated the required output format, with 37% (CIRR) and 56% (FashionIQ) of instances failing on the first pass and 9% and 12% remaining unresolved even after six retry rounds, and the subsequent VQA filter added another full inference pass.

We thus streamline the pipeline with two modifications, while keeping the remaining instructions of ReCALL’s captioning prompt unchanged. First, we employ contrastive captioning strategy, which additionally presents the original target $I_{t}$ alongside $I_{r}$ and $I_{h}$ , and instruct the model to describe $I_{h}$ such that the text no longer applies to $I_{t}$ . Note that $I_{t}$ serves purely as a conditioning signal and is omitted from the augmented triplet. Second, we replace the local captioner with GPT-5.6-luna [ 55 ] via the batch API, which can follow both the contrast instruction and the output format in a single pass, removing the retry loop and separate verification stage.

Compared with the ReCALL’s two-image prompting strategy on 100 sampled mined queries per dataset, we found that our contrastive captioning successfully yields an edited modification text while the two-image prompting strategy produced 27.0% (CIRR) and 33.0% (FashionIQ) of modification texts unchanged. Furthermore, among the edited queries, we found that 30.1% (CIRR) and 10.5% (FashionIQ) of the modification texts rewritten by the two-image prompting strategy were judged by GPT-5.6-luna to describe the original target $I_{t}$ better than the mined target $I_{h}$ , while our contrastive captioning reduced this reversal rate to 7.0% and 0.0%, respectively. Consequently, as shown in Fig. 6 , our contrastive captioning yields larger or comparable gains than the augmentation strategy of ReCALL on top of FactEmbed. This demonstrates that our streamlined pipeline is not only more efficient, as it requires neither a caption retry loop nor a separate verification stage, but also yields higher-quality augmentation. We remark that other than these modifications, we followed ReCALL [ 76 ] to mine five hard negatives per composed query, resulting in 57,476 (CIRR) and 56,499 (FashionIQ) captioning requests. This incurs a one-time cost of only $22.82 (CIRR) and $26.17 (FashionIQ), which is highly economical compared to renting GPU servers to deploy a local MLLM, which often struggles with strict output formatting and thus requires repeated retries.


#### F.2 Hard Negative Filtering

Hard negative mining occasionally yields near-duplicate instances that are virtually identical to the annotated target despite holding distinct identifiers in the same dataset. Rewriting such a pair forces the model to generate text that separates two near-identical images, teaching the retriever to incorrectly push them apart. To prevent this, we filter out these pairs prior to contrastive captioning based on visual feature similarity via DINOv2 [ 56 ] before we query the MLLM to write the captions. Specifically, we encoded each image using a frozen DINOv2 ViT-B/14 backbone and mean-pooled the patch tokens into a single descriptor, discarding hard negative candidates ( $I_{h}$ ) that exhibit a cosine similarity exceeding $0.99$ with the original target ( $I_{t}$ ). This filtering step removes $743$ CIRR instances and $277$ FashionIQ instances out of $58,219$ and $56,776$ mined pairs, respectively. For Stage 3, we additionally filter mislabeled original triplets: when mining with the Stage 2 model, we also record the rank of the ground-truth target, and drop the 3% of original triplets whose ground truth is ranked lowest.


#### F.3 Post-training

Finally, for the post-training stage, we optimize our model using the total objective, described in Eq. 8 , similarly to stage 2. Note that we construct each batch for CIRR by grouping an original triplet with its MLLM-augmented counterparts following [ 76 ] . This strategy supplies high-quality in-batch hard negatives, explicitly encouraging the model to discern subtle visual differences.


#### F.4 Limitation of Contrastive Captioning

While our contrastive captioning mitigates noisy supervision in both the original and augmented triplets, a limitation remains when scaling up the augmentation. Contrastive captioning conditions each rewrite only on the original target $I_{t}$ , so it reduces ambiguity between $I_{t}$ and a hard negative but not among the multiple hard negatives mined for the same composed query. As more hard negatives are mined per query, i.e., each pair of reference image $I_{r}$ and modification text $T$ , we expect these sibling hard negatives to increasingly overlap in semantics, so that a modification text written for one may equally describe another, introducing false negatives within the augmented set. An effective augmentation strategy for CIR therefore requires conditioning across both the original and augmented sets, so that each generated instruction captures features that distinguish its target from all other candidates of the same query. Nevertheless, since the augmented triplets consistently improve CIR performance in our experiments, we will publicly release them to facilitate future research.

### Appendix G Qualitative Results

In Fig. 7 , Fig. 8 , Fig. 9 , and Fig. 10 , we present qualitative comparisons between FactEmbed and our baseline (Qwen2.5-VL-7B-Instruct [ 1 ] fine-tuned via DoRA [ 46 ] ). In CIR, modifying a reference image with text often projects the query into a broad semantic space where multiple target images can be considered valid matches. Therefore, rather than restricting our analysis to Top-1 prediction, we examine the Top-8 retrieved results to better assess the overall alignment between the composed query and the retrieved distribution.

In the first example of Fig. 7 , which belongs to the dress category of FashionIQ dataset, the query specifies an item that is “more fashionable and party wear and is cream and brown with animal print”. While both models successfully capture the desired color scheme, FactEmbed ranks candidates that accurately reflect the fine-grained “animal print” pattern higher than the baseline. In the second example, the baseline struggles with structural modifications, incorrectly retrieving an item with short sleeves at Rank-2 and entirely ignoring the requested “strap” detail at Rank-3. Conversely, FactEmbed strictly adheres to these fine-grained structural constraints across the top ranked candidates. Fig. 8 further highlights a common failure mode in standard contrastive learning, which fails to handle negative constraints. For the query containing the phrase “instead of superman logo”, the baseline fails to disentangle the negated element, retrieving images containing the superman logo. In contrast, FactEmbed successfully suppresses the negated visual element while maintaining the core semantics of the reference image.

This gap in multimodal understanding extends to the open-domain CIRR dataset. As shown in the first example of Fig. 10 , the query requires the model to identify “map displayed on the screen” of a smartphone. While the baseline is easily distracted by generic smartphone images, FactEmbed accurately grounds the text modification into the precise visual context. Also, for queries involving relative counting or relational reasoning (e.g., second example), the baseline exhibits a severe lack of compositional understanding. Overall, we find that the baseline trained with standard contrastive learning often ignores the comparative conditions, while FactEmbed captures these relationships more faithfully.
